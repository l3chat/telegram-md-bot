## Reddit / forum post

### Suggested title

**I built an open-source Telegram bot that converts Markdown + media into Rich Messages**

### Body

I often wanted to move long Markdown documents into Telegram without rebuilding headings, lists, tables, code, formulas and media by hand.

So I built **Markdown → Rich Message**: a Telegram bot that takes Markdown text or a Markdown file and produces a structured Telegram Rich Message.

Current features:

- Markdown headings, lists, quotes and links
- tables and code blocks
- formulas
- photos, audio, video and files
- automatic media linking
- safe splitting of long documents
- localized UI in English, Russian, German, French and Ukrainian
- a built-in `/test` page with the original Markdown source as a tutorial
- open-source Cloudflare Worker + Durable Objects backend

# Publishing checklist

1. Wait for the Telegram profile rate limit to expire.
2. Run `/syncprofile` once.
3. Verify Name / About / Description / commands in the bot profile.
4. Post the short announcement in 2–3 Telegram communities where it is relevant.
5. Publish the Reddit/forum version in communities that allow project showcases.
6. Submit a Show HN post.
7. Add the bot to relevant Telegram bot directories.
8. Check `/stats` after 24 hours, 7 days and 30 days.
9. Compare DAU / 7-day users / MAU instead of judging only by clicks.
10. Collect formatting failures and turn them into regression tests.

## What to measure

The most useful early signals are:

- how many new users try the bot;
- how many return within 7 days;
- how many Rich Messages are created per active user;
- which errors are most frequent;
- whether users discover and use `/test`.

Avoid optimizing for raw update count alone; one user can generate many Telegram updates.
