# Markdown → Rich Message

**Telegram Markdown & Media Converter**

Markdown → Rich Message перетворює Markdown-текст і файли на Telegram Rich Messages.

Підтримуються довгі структуровані тексти, таблиці, код, цитати, посилання, формули, фото, аудіо, голосові повідомлення, відео та документи.

Користувач може спочатку надіслати медіа, а потім Markdown. Бот автоматично створює внутрішні Telegram-посилання. Надто довгі документи автоматично розбиваються на кілька Rich Messages.

Чернетки тимчасово зберігаються в Cloudflare Durable Objects і автоматично видаляються не пізніше ніж через 24 години.

Мови: English, Русский, Deutsch, Français, Українська.

Команда `/test` показує демонстраційну Rich Message сторінку прямо в чаті.

Створено за допомогою **GPT-6.1**.
