# Конфиденциальность — Telegram Markdown Formatter

**Бот:** @tgMdFormatter_bot

Создан с помощью **GPT-6.1** · GitHub: https://github.com/l3chat/telegram-md-bot

Бот обрабатывает только содержимое, которое пользователь отправляет для создания Telegram Rich Messages.

## Что может временно храниться

- Markdown-текст;
- Telegram `file_id`;
- имена или временные псевдонимы файлов;
- порядок медиа;
- состояние альбома/черновика.

Черновики изолированы по чату и пользователю.

## Срок хранения

Черновик удаляется:

- после успешной сборки Rich Message; или
- автоматически не позднее чем через 24 часа после последней активности.

Сами медиафайлы **не копируются в Durable Object**. Используются ссылки `file_id` на файлы, уже хранящиеся в Telegram.

## Использование данных

Присланный контент не используется для рекламы, профилирования или обучения моделей.

Пользовательские данные не продаются.

Telegram и Cloudflare могут обрабатывать технические данные запросов, доставки и инфраструктуры в рамках собственных сервисов и политик.
