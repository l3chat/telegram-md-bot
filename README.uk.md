# Telegram Markdown Formatter Bot

Публічний Telegram-бот, який перетворює Markdown на **Telegram Rich Messages**.

Бот: **@tgMdFormatter_bot**

Створено за допомогою **GPT-6.1** · Вихідний код: https://github.com/l3chat/telegram-md-bot

## Можливості

- Markdown → Telegram Rich Message
- автоматичне розбиття надто довгих документів на кілька Rich Messages
- заголовки, списки, task lists, цитати, таблиці, блоки коду, посилання та формули
- фото, аудіо, голосові повідомлення, відео та файли всередині Rich Message
- автоматичне прив’язування медіа без ручних `tg://...` посилань
- Markdown як текст або файли `.md`, `.markdown`, `.txt`
- тимчасові чернетки у Cloudflare Durable Objects
- автоматичне видалення чернеток через 24 години
- інтерфейс англійською, російською, німецькою, французькою та українською

## Швидке використання

### Лише текст

Надішліть Markdown прямо боту:

```md
# Заголовок

Це **жирний текст**, а це *курсив*.

- один
- два
```

Бот поверне Rich Message. Надто довгі документи автоматично розбиваються за безпечними межами Markdown.

### Текст із медіа

1. Спочатку надішліть фото, аудіо, відео, голосові повідомлення або файли.
2. Потім надішліть Markdown-текст або файл `.md/.txt`.
3. Бот сам створить внутрішні Telegram-посилання.

Приклад:

```md
![](photo.jpg "Підпис")
```

Якщо `photo.jpg` було надіслано раніше, файл буде вставлено саме тут. Невикористані медіа автоматично додаються наприкінці.

## Команди

- `/help` — довідка
- `/test` — показати локалізовану Test Page
- `/media` — показати медіа поточної чернетки
- `/send` — зібрати та надіслати чернетку
- `/clear` — видалити чернетку
- `/privacy` — конфіденційність

Мова вибирається автоматично за Telegram `language_code`.

## Публічний профіль Telegram

Worker автоматично синхронізує через Bot API:

- локалізоване меню команд;
- ім’я бота;
- короткий опис;
- повний опис.

Підтримуються **EN / RU / DE / FR / UK**.

## Конфіденційність

`/privacy` показує локалізовану політику.

```text
https://tg-md-bot.lechat-reg.workers.dev/privacy?lang=uk
```

Окремий файл: [PRIVACY.uk.md](PRIVACY.uk.md).

## Архітектура

```text
Telegram
   ↓ webhook
Cloudflare Worker
   ↓
DraftSession Durable Object
   ↓
Telegram Bot API / sendRichMessage
```

Для кожної пари chat/user використовується окремий Durable Object. Тимчасово зберігаються Markdown, Telegram `file_id`, назви/аліаси файлів, порядок медіа та стан альбому. Самі медіафайли залишаються у Telegram.

## Обмеження

Бот використовує приблизно **30 000 символів** як безпечний цільовий розмір однієї Rich Message і автоматично ділить довші документи. Медіа прив’язуються до тієї частини, де є відповідне посилання. Поточний максимум — **50 медіаелементів** у підготовленому документі.
