# Markdown → Rich Message

**Telegram Markdown & Media Converter**

Markdown → Rich Message transforme du texte et des fichiers Markdown en Telegram Rich Messages.

Il prend en charge les longs textes structurés, tableaux, code, citations, liens, formules, photos, audio, messages vocaux, vidéo et documents.

L’utilisateur peut envoyer les médias d’abord, puis Markdown. Le bot crée automatiquement les liens Telegram internes. Les documents trop longs sont automatiquement répartis en plusieurs Rich Messages.

Les brouillons sont stockés temporairement dans Cloudflare Durable Objects et sont supprimés automatiquement au plus tard après 24 heures.

Langues : English, Русский, Deutsch, Français, Українська.

La commande `/test` affiche une page de démonstration Rich Message directement dans le chat.

Créé avec **GPT-6.1**.
