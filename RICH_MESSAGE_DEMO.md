# Telegram Rich Message — демонстрация

Это пример документа, созданного из **Markdown** и превращённого ботом в одно Rich Message.

Можно использовать **жирный текст**, *курсив*, ~~зачёркнутый текст~~ и `inline code`.

Также можно комбинировать **жирный и *курсив*** внутри одного предложения.

---

## 2. Списки

- первый пункт
- второй пункт
- третий пункт

Нумерованный список:

1. подготовить текст
2. отправить медиа
3. отправить Markdown
4. получить одно Rich Message

Список задач:

- [x] Markdown
- [x] таблицы

- [x] аудио
- [x] видео

## 3. Цитата

> Rich Message позволяет объединить длинный структурированный текст,
> таблицы, код и медиа в одном сообщении Telegram.

Обычный текст после цитаты.

## 6. Код

Небольшой Python-пример:

```python
def rich_message(name):
    return f"Hello, {name}!"

print(rich_message("Telegram"))
```

Команда shell:

```bash
echo "Markdown → Rich Message"
```

## Как тестировать медиа

Перед отправкой этого файла боту можно заранее отправить:

- фотографию, которую бот назовёт, например, `photo_1`;
- аудиофайл `sample.mp3`;
- видео `demo.mp4`;
- документ `manual.pdf`.

Команда `/media` показывает накопленные медиа.

Если удалить из Markdown явные ссылки на медиа, но сначала отправить файлы боту, бот должен автоматически добавить неиспользованные вложения в конец Rich Message.

После успешной сборки `/media` должен показывать пустой черновик.
