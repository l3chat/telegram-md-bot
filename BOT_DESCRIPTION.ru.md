# Markdown → Rich Message

**Telegram Markdown & Media Converter**

Markdown → Rich Message преобразует Markdown-текст и файлы в Telegram Rich Messages.

Поддерживаются длинные структурированные тексты, таблицы, код, цитаты, ссылки, формулы, фотографии, аудио, голосовые сообщения, видео и документы.

Пользователь может сначала отправить медиа, а затем Markdown. Бот автоматически создаёт внутренние Telegram-ссылки и собирает результат. Слишком длинные документы автоматически разбиваются на несколько Rich Messages.

Черновики временно хранятся в Cloudflare Durable Objects и автоматически удаляются не позднее чем через 24 часа.

Интерфейс: English, Русский, Deutsch, Français, Українська.

Команда `/test` показывает демонстрационную Rich Message страницу прямо в чате.

Бот создан с помощью **GPT-6.1**.
