# Privacy Notice — Telegram Markdown Formatter

**Bot:** @tgMdFormatter_bot

Built with **GPT-6.1** · GitHub: https://github.com/l3chat/telegram-md-bot

The bot processes only content that users send for formatting into Telegram Rich Messages.

## What may be stored temporarily

- Markdown text;
- Telegram `file_id` values;
- file names or temporary aliases;
- media ordering;
- album/draft state.

Temporary draft state is isolated by chat and user.

## Retention

Draft state is deleted:

- after successful Rich Message assembly; or
- automatically no later than 24 hours after the latest draft activity.

Media binaries are **not copied into Durable Object storage**. Telegram-hosted file references are used instead.

## Use of data

Submitted content is not used for advertising, profiling, or model training.

User data is not sold.

Telegram and Cloudflare may process technical request, delivery, and infrastructure metadata according to their own services and policies.
