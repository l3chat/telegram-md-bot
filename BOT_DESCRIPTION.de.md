# Markdown → Rich Message

**Telegram Markdown & Media Converter**

Markdown → Rich Message wandelt Markdown-Text und Dateien in Telegram Rich Messages um.

Unterstützt werden lange strukturierte Texte, Tabellen, Code, Zitate, Links, Formeln, Fotos, Audio, Sprachnachrichten, Video und Dokumente.

Benutzer können zuerst Medien und danach Markdown senden. Der Bot erzeugt die internen Telegram-Links automatisch. Zu lange Dokumente werden automatisch auf mehrere Rich Messages verteilt.

Entwürfe werden temporär in Cloudflare Durable Objects gespeichert und spätestens nach 24 Stunden automatisch gelöscht.

Sprachen: English, Русский, Deutsch, Français, Українська.

Der Befehl `/test` zeigt eine Rich-Message-Testseite direkt im Chat.

Erstellt mit **GPT-6.1**.
